
Overview:

The JDHS Tutoring Program is a platform designed to help students at Jonathan Dayton High School easily find peer tutors. It allows users to see which students are available for tutoring and what subjects they teach, making academic support more accessible and organized.



Goals:

-Connect struggling students with peer tutors easily and efficiently

-Allow peer tutors themselves to find students in need of help, aiding in aquiring volunteer hours

-Encourage well versed students to become peer tutors by giving them an easy path to do so










Features:



-Subject-based tutoring requests

-Real-time tutor availability

-Tutor profiles with names, interests, and academic strengths listed

-Request Status tracking (Pending, accepted, Completed, etc...)









Usage:

-Students will select a subject and immediately be shown a filtered list of tutors who fit that criteria

-Tutors can mark themselves available for specific subjects

-Tutors can accept requests and connect with students








Installation:

-Clone repository

-Ensure C++ files are working correctly using Xcode

-Build and run on an iOS simulator/device (School Ipad)
